## Image Usage Guidelines

- Prefer freely licensed images from Wikimedia Commons.
- Record the original source URL and creator.
- Follow the attribution and share-alike requirements of each license.
- Do not use copyrighted stock photographs without permission.
- Use brand-level images when a model-specific image is unavailable.
