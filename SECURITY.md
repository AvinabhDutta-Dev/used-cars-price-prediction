# Security Policy

## Supported Versions

Security fixes are generally focused on the latest version available on the `main` branch. Older versions may not receive security updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub Issues or public pull requests.

If GitHub's private vulnerability reporting is available for this repository:

1. Open the repository's **Security** tab.
2. Select **Advisories** or **Report a vulnerability**.
3. Submit a private vulnerability report with the details described below.

If private vulnerability reporting is unavailable, use the contact method listed on the repository maintainer's GitHub profile to report the issue privately.

### What to Include

When reporting a potential vulnerability, please include as much of the following information as possible:

- A clear description of the vulnerability and its potential impact.
- The affected file, component, endpoint, or commit, if known.
- The steps required to reproduce the issue.
- A proof of concept or relevant screenshots, where safe and appropriate.
- Any suggested mitigation or fix.
- A way to contact you if clarification is needed.

Please do not include real passwords, API keys, access tokens, personal data, or other live secrets in your report. Use redacted or dummy values instead.

## Response and Disclosure

The maintainer will review reports and may request additional information to understand and reproduce the issue. Please allow reasonable time for investigation and remediation before making a vulnerability public.

There is currently no guaranteed response or resolution time. If a report is accepted, the maintainer will work toward an appropriate fix and coordinate public disclosure where applicable.

## Scope

This policy applies to security vulnerabilities in this repository and its project code. It does not cover vulnerabilities in third-party services or dependencies that are outside the maintainer's control; those should also be reported to the relevant project or vendor.
